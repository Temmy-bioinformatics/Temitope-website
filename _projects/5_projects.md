Species delimitation can be challenging when closely related lineages show incomplete lineage sorting, introgression, and complex population histories. As an independent computational project, I am exploring whether **machine learning can be used to identify genomic patterns that help distinguish species boundaries** in closely related taxa.

### What I am exploring

The project uses the *Phoxinus* species complex as a test case for developing and evaluating machine-learning approaches to species delimitation. The broader aim is to investigate whether genomic features can be used to classify individuals and identify patterns that may help distinguish evolutionary lineages.

Key areas of exploration include:

- Preparing **genome-wide genomic data** for machine-learning applications
- Developing informative genomic features from SNP and population-level data
- Evaluating **supervised learning approaches** for distinguishing closely related taxa
- Comparing model predictions with established population-genomic and species-delimitation results
- Investigating how **admixture and hybrid individuals** affect classification performance
- Evaluating model performance using appropriate training, validation, and test datasets
- Exploring which genomic features contribute most strongly to model predictions
- Assessing whether machine-learning approaches can complement conventional evolutionary genomic methods

### Why machine learning?

Traditional species delimitation approaches generally rely on explicit evolutionary models or summary statistics derived from genomic data. Machine-learning approaches provide an alternative framework for identifying complex patterns in high-dimensional genomic datasets.

A particular challenge is distinguishing genuine species-level signal from patterns caused by **population structure, incomplete lineage sorting, and introgression**. Using *Phoxinus* as a biologically complex test case provides an opportunity to investigate how machine-learning models perform under these conditions.

### Connecting machine learning with evolutionary genomics

An important goal of the project is not simply to maximise classification accuracy, but to understand **what the models are learning** and whether their predictions correspond to biologically meaningful genomic patterns.

Model predictions will therefore be compared with independent evidence from population structure, phylogenomic relationships, species delimitation, and introgression analyses.

This provides a way to explore how machine learning might complement existing computational approaches to **species boundaries and evolutionary genomics**.
